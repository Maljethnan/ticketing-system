-------------------------------------------------------------------------------
مشكلة ١: خطأ الاتصال بقاعدة البيانات
-------------------------------------------------------------------------------
الخطأ: A network-related or instance-specific error occurred while establishing...
الحلول:
1. تأكد أن SQL Server Service يعمل: services.msc → SQL Server (SQLEXPRESS)
2. تأكد أن TCP/IP مفعل: SQL Server Configuration Manager → Network Configurations
3. تحقق من اسم السيرفر في appsettings.json
4. تأكد أن Windows Firewall يسمح بالمنفذ 1433
5. جرب الاتصال عبر SSMS بنفس بيانات الاتصال

-------------------------------------------------------------------------------
مشكلة ٢: خطأ JWT Token
-------------------------------------------------------------------------------
الخطأ: IDX10503: Signature validation failed
الحلول:
1. تأكد أن JWT_SECRET_KEY في Environment Variables يتطابق مع appsettings.json
2. تأكد أن المفتاح طوله 64 حرفاً على الأقل
3. أعد تشغيل التطبيق بعد تغيير المفتاح

-------------------------------------------------------------------------------
مشكلة ٣: خطأ Active Directory
-------------------------------------------------------------------------------
الخطأ: The server is not operational
الحلول:
1. تأكد أن AD_DOMAIN متغير بيئي صحيح
2. تأكد أن حساب الخدمة لديه صلاحية قراءة المستخدمين
3. تحقق من DNS: nslookup NAZHA.LOCAL
4. تأكد أن السيرفر متصل بالنطاق

-------------------------------------------------------------------------------
مشكلة ٤: خطأ رفع الملفات
-------------------------------------------------------------------------------
الخطأ: Access to the path is denied
الحلول:
1. تأكد أن مجلد C:\TicketingSystem\Attachments موجود
2. تأكد أن حساب الخدمة لديه Full Control
3. تحقق من مسار FileStorage.BasePath في appsettings.json

-------------------------------------------------------------------------------
مشكلة ٥: خطأ SignalR / الإشعارات لا تعمل
-------------------------------------------------------------------------------
الحلول:
1. تأكد أن Hub مسجّل في Program.cs: app.MapHub<NotificationHub>("/notificationHub")
2. تأكد أن المتصفح يدعم WebSockets
3. تحقق من Console في المتصفح (F12) لأي أخطاء WebSocket
4. إذا كنت تستخدم Proxy، تأكد أنه لا يحجب WebSocket connections

-------------------------------------------------------------------------------
مشكلة ٦: خطأ بناء المشروع
-------------------------------------------------------------------------------
الخطأ: Unable to find package Microsoft.EntityFrameworkCore.SqlServer
الحلول:
1. تأكد من تثبيت .NET 8 SDK: dotnet --version (يجب أن يكون 8.x)
2. إذا كان السيرفر معزولاً، حمّل الحزم مسبقاً:
   dotnet restore --source <local-cache-path>
3. أو أنشئ local NuGet cache:
   mkdir C:\NuGetCache
   dotnet nuget add source C:\NuGetCache --name LocalCache
   ثم انقل ملفات .nupkg إليه

-------------------------------------------------------------------------------
مشكلة ٧: خطأ Collation
-------------------------------------------------------------------------------
الخطأ: Cannot resolve the collation conflict between "SQL_Latin1_General_CP1_CI_AS" and "Arabic_CI_AS"
الحلول:
1. أعد إنشاء قاعدة البيانات بـ Arabic_CI_AS
2. أو عدّل Collation الجدول:
   ALTER TABLE [TableName] ALTER COLUMN [ColumnName] NVARCHAR(100) COLLATE Arabic_CI_AS

-------------------------------------------------------------------------------
مشكلة ٨: خطأ الصلاحيات (403 Forbidden)
-------------------------------------------------------------------------------
الحلول:
1. تحقق من RolePermissions في قاعدة البيانات
2. تأكد أن المستخدم مرتبط بدور صحيح في UserRoles
3. تحقق من UserDepartmentAccess إذا كانت المشكلة تتعلق بإدارة معينة
4. راجع AuditLog لمعرفة محاولة الوصول المرفوضة

-------------------------------------------------------------------------------
مشكلة ٩: خطأ تصعيد التذاكر لا يعمل
-------------------------------------------------------------------------------
الحلول:
1. تأكد أن EscalationMonitorService يعمل (Background Service)
2. تحقق من EscalationRules في قاعدة البيانات
3. راجع سجلات التطبيق: logs/app.log
4. تأكد أن التوقيت الصحيح مضبوط على السيرفر

-------------------------------------------------------------------------------
مشكلة ١٠: خطأ أداء بطيء
-------------------------------------------------------------------------------
الحلول:
1. تأكد من وجود Indexes على الجداول الرئيسية
2. استخدم SQL Server Profiler لتحديد الاستعلامات البطيئة
3. فعّل Query Plan Cache
4. إذا تجاوز عدد التذاكر 100,000، أضف Partitioning على جدول Tickets حسب التاريخ
