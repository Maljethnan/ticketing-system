نظام تتبع المشكلات التقنية — هيئة الرقابة ومكافحة الفساد (نزاها)
ملف: متطلبات البيئة التقنية
===============================================================================

قبل البدء بالتنصيب، تأكد من توفر المتطلبات التالية على السيرفر:

-------------------------------------------------------------------------------
١. نظام التشغيل
-------------------------------------------------------------------------------
• Windows Server 2019 أو أحدث (موصى به: Windows Server 2022)
• يجب أن يكون السيرفر ضمن نطاق Active Directory
• لا يحتاج اتصال بالإنترنت

-------------------------------------------------------------------------------
٢. قاعدة البيانات
-------------------------------------------------------------------------------
• SQL Server 2019 أو أحدث (Express أو Standard أو Enterprise)
• Collation مطلوب: Arabic_CI_AS
• مساحة تخزين مبدئية: 10 GB (قابلة للزيادة)
• حساب خدمة (Service Account) بصلاحيات db_owner على قاعدة البيانات

-------------------------------------------------------------------------------
٣. بيئة التطوير / التنفيذ
-------------------------------------------------------------------------------
• .NET 8 SDK (للتطوير) أو .NET 8 Runtime (للتشغيل فقط)
  التحميل: https://dotnet.microsoft.com/download/dotnet/8.0
  ⚠️ حمّل الحزمة مسبقاً عبر جهاز متصل بالإنترنت ثم انقلها

• Visual Studio 2022 Community/Professional (للتطوير فقط)
  مع حزم العمل: ASP.NET and web development + .NET desktop development

-------------------------------------------------------------------------------
٤. خدمات إضافية مطلوبة
-------------------------------------------------------------------------------
• Active Directory Domain Services — لتوثيق هوية الموظفين
• IIS (اختياري) — إذا أردت نشر التطبيق كـ Web Application
  أو يمكنك تشغيله مباشرة كـ Self-Hosted Service

-------------------------------------------------------------------------------
٥. المسارات المطلوبة على السيرفر
-------------------------------------------------------------------------------
• مجلد المرفقات: C:\TicketingSystem\Attachments
  - أنشئ المجلد يدوياً
  - امنح حساب الخدمة صلاحية Read/Write عليه

-------------------------------------------------------------------------------
٦. المتغيرات البيئية (Environment Variables)
-------------------------------------------------------------------------------
يجب إعداد المتغيرات التالية على مستوى النظام (System Environment Variables):

| المتغير | القيمة | الوصف |
|---------|--------|-------|
| AD_DOMAIN | NAZHA.LOCAL | اسم نطاق Active Directory |
| JWT_SECRET_KEY | [مفتاح عشوائي 64 حرف] | مفتاح تشفير JWT |
| ATTACHMENTS_PATH | C:\TicketingSystem\Attachments | مسار حفظ المرفقات |

لمعرفة كيفية إضافة متغيرات بيئية:
  System Properties → Advanced → Environment Variables → System variables → New

-------------------------------------------------------------------------------
٧. المنافذ المفتوحة (Ports)
-------------------------------------------------------------------------------
| المنفذ | البروتوكول | الاستخدام |
|--------|------------|-----------|
| 5001 | HTTPS | واجهة API |
| 5002 | HTTPS | واجهة Blazor Server |
| 1433 | TCP | SQL Server |

⚠️ تأكد من فتح هذه المنافذ في Windows Firewall

-------------------------------------------------------------------------------
٨. المتطلبات الأمنية (مستوى NCA ECC-2:2024)
-------------------------------------------------------------------------------
• شهادة SSL/TLS ذاتية التوقيع (Self-Signed Certificate) أو من CA داخلي
• تفعيل TDE على قاعدة البيانات (يتطلب SQL Server Enterprise)
• سياسة كلمات مرور قوية (12+ حرف، أحرف كبيرة وصغيرة وأرقام ورموز)
• MFA (TOTP أو Smart Card) — سيتم تفعيله لاحقاً
