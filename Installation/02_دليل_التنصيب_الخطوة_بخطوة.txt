نظام تتبع المشكلات التقنية — هيئة الرقابة ومكافحة الفساد (نزاها)
ملف: دليل التنصيب خطوة بخطوة
===============================================================================

-------------------------------------------------------------------------------
الخطوة ١: إعداد قاعدة البيانات
-------------------------------------------------------------------------------
1. افتح SQL Server Management Studio (SSMS)
2. اتصل بسيرفر قاعدة البيانات
3. افتح ملف: Database\Setup_Database.sql
4. تأكد من أن Collation السيرفر هو Arabic_CI_AS
   (إذا لم يكن كذلك، أعد تثبيت SQL Server مع هذا الـ Collation)
5. نفّذ السكربت بالكامل
6. تحقق من إنشاء الجداول:
   - يجب أن يكون لديك 22 جدولاً على الأقل
   - تحقق من وجود المستخدم الافتراضي: admin

-------------------------------------------------------------------------------
الخطوة ٢: إعداد مجلد المرفقات
-------------------------------------------------------------------------------
1. أنشئ المسار: C:\TicketingSystem\Attachments
2. انقر بزر الماوس الأيمن → Properties → Security
3. أضف حساب الخدمة (Service Account) أو NETWORK SERVICE
4. امنحه صلاحيات: Full Control
5. تأكد من عدم مشاركة المجلد عبر الشبكة (Network Share)

-------------------------------------------------------------------------------
الخطوة ٣: إعداد المتغيرات البيئية
-------------------------------------------------------------------------------
1. اضغط Win + R → اكتب: sysdm.cpl
2. تبويب Advanced → Environment Variables
3. في System variables → New:
   - Variable name: AD_DOMAIN
     Variable value: NAZHA.LOCAL (أو اسم نطاقكم الفعلي)
   - Variable name: JWT_SECRET_KEY
     Variable value: [أنشئ مفتاح عشوائي]
     يمكنك توليد مفتاح عبر PowerShell:
       -DotNet -Command "[Convert]::ToBase64String([Security.Cryptography.RandomNumberGenerator]::GetBytes(64))"
   - Variable name: ATTACHMENTS_PATH
     Variable value: C:\TicketingSystem\Attachments

-------------------------------------------------------------------------------
الخطوة ٤: تعديل ملف الإعدادات
-------------------------------------------------------------------------------
افتح الملف: TicketingSystem.API\appsettings.json

عدّل القيم التالية:
1. ConnectionStrings.DefaultConnection:
   ضع مسار سيرفر قاعدة البيانات الفعلي
   مثال: Server=SERVERNAME\SQLEXPRESS;Database=TicketingSystem;Trusted_Connection=True;TrustServerCertificate=True;

2. Jwt.SecretKey:
   استبدل القيمة بمفتاح JWT الذي أنشأته في الخطوة السابقة

3. FileStorage.BasePath:
   تأكد أنه يتطابق مع مسار المرفقات

-------------------------------------------------------------------------------
الخطوة ٥: بناء المشروع
-------------------------------------------------------------------------------
1. افتح Terminal (PowerShell) كمسؤول
2. انتقل إلى مجلد المشروع:
   cd C:\TicketingSystem_Project
3. نفّذ الأمر:
   dotnet restore
4. ثم:
   dotnet build --configuration Release

⚠️ إذا ظهرت أخطاء في الحزم (NuGet packages)، تأكد من أن:
   - .NET 8 SDK مثبت
   - لا يوجد جدار ناري يمنع الاتصال بـ nuget.org
   - إذا كان السيرفر معزولاً تماماً، حمّل الحزم مسبقاً عبر جهاز متصل بالإنترنت
     واستخدم: dotnet restore --source <path-to-local-nuget-cache>

-------------------------------------------------------------------------------
الخطوة ٦: نشر التطبيق
-------------------------------------------------------------------------------
خيار أ: تشغيل مباشر (Self-Hosted)
1. في مجلد TicketingSystem.API:
   dotnet run --project TicketingSystem.API --urls https://*:5001
2. في نافذة أخرى، في مجلد TicketingSystem.Web:
   dotnet run --project TicketingSystem.Web --urls https://*:5002

خيار ب: كخدمة Windows Service
1. استخدم أداة: dotnet publish -c Release -o C:\TicketingSystem\Published
2. أنشئ خدمة Windows:
   sc create TicketingSystem binPath= "C:\TicketingSystem\Published\TicketingSystem.API.exe" start= auto
3. ابدأ الخدمة:
   net start TicketingSystem

خيار ج: نشر على IIS
1. dotnet publish -c Release -o C:\inetpub\wwwroot\TicketingSystem
2. افتح IIS Manager → Add Website
3. Physical path: C:\inetpub\wwwroot\TicketingSystem
4. Binding: HTTPS on port 5001
5. Application Pool: .NET CLR Version = No Managed Code

-------------------------------------------------------------------------------
الخطوة ٧: اختبار التشغيل
-------------------------------------------------------------------------------
1. افتح متصفح Edge/Chrome على أي جهاز في الشبكة
2. اذهب إلى: https://[سيرفر]:5002
3. سجّل الدخول:
   - اسم المستخدم: admin
   - كلمة المرور: Admin@2025!
4. يجب أن تظهر لوحة التحكم الرئيسية

⚠️ مهم جداً: غيّر كلمة مرور admin فوراً بعد أول دخول!

-------------------------------------------------------------------------------
الخطوة ٨: إضافة المستخدمين والإدارات
-------------------------------------------------------------------------------
1. اذهب إلى الإعدادات → الإدارات
2. أضف الإدارات العامة أولاً، ثم الإدارات الفرعية
3. أضف الأنظمة التقنية التي تريد تتبع مشكلاتها
4. أضف المستخدمين وأرسل لهم بيانات الدخول
5. عيّن المختصين لكل نظام
