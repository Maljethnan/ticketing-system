هذا المشروع يحتوي على نظام متكامل لتتبع وإدارة المشكلات التقنية الداخلية.

-------------------------------------------------------------------------------
هيكل المجلدات:
-------------------------------------------------------------------------------
TicketingSystem_Project/
├── TicketingSystem.sln              ← ملف الحل الرئيسي (افتحه بـ Visual Studio)
├── TicketingSystem.Core/            ← الطبقة الأساسية (كيانات، DTOs، واجهات)
│   ├── Entities/                    ← كائنات قاعدة البيانات
│   ├── DTOs/                        ← كائنات نقل البيانات
│   └── Interfaces/                  ← واجهات الخدمات
├── TicketingSystem.Data/            ← طبقة البيانات (DbContext، Repositories)
│   ├── Context/                     ← AppDbContext
│   ├── Seeders/                     ← بيانات أولية
│   └── Repositories/                ← مستودعات البيانات
├── TicketingSystem.API/             ← واجهة REST API
│   ├── Controllers/                 ← نقاط النهاية (Endpoints)
│   ├── Services/                    ← خدمات الأعمال
│   ├── Middleware/                  ← وسائط المعالجة
│   └── Hubs/                        ← SignalR للتواصل الفوري
├── TicketingSystem.Web/             ← واجهة المستخدم (Blazor Server)
│   ├── Pages/                       ← الصفحات
│   ├── Layouts/                     ← القوالب
│   ├── Services/                    ← خدمات العميل
│   └── wwwroot/css/site.css         ← التنسيقات
├── Database/                        ← ملفات قاعدة البيانات
│   └── Setup_Database.sql           ← سكربت إنشاء القاعدة بالكامل
├── Installation/                    ← أدلة التنصيب
│   ├── 01_متطلبات_البيئة.txt       ← المتطلبات التقنية
│   ├── 02_دليل_التنصيب_الخطوة_بخطوة.txt ← خطوات التنصيب التفصيلية
│   ├── 03_دليل_الأمان_والتشفير.txt     ← إجراءات الأمان والتشفير
│   └── 04_دليل_استكشاف_الأخطاء.txt   ← حل المشاكل الشائعة
└── README.txt                       ← هذا الملف

-------------------------------------------------------------------------------
البدء السريع:
-------------------------------------------------------------------------------
1. اقرأ: Installation\01_متطلبات_البيئة.txt
2. نفّذ: Database\Setup_Database.sql
3. عدّل: TicketingSystem.API\appsettings.json
4. بناء: dotnet build --configuration Release
5. تشغيل: dotnet run --project TicketingSystem.API

التقنيات المستخدمة:
-------------------------------------------------------------------------------
• Backend: ASP.NET Core 8 Web API
• Frontend: Blazor Server
• Database: SQL Server 2019+
• Authentication: JWT + Active Directory
• Real-time: SignalR
• Architecture: Clean Architecture (Core → Data → API → Web)
